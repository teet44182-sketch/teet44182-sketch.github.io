### California Love Hotel

**Network Infrastructure Project**

ออกแบบและตั้งค่า network infrastructure สำหรับโรงแรม จำลองการทำงานเสมือนจริง

**Highlights:**
- **60+ devices** — endpoints, switches, routers, servers
- **5 VLANs** — แยกแผนก (Front Desk, Housekeeping, Management, Guest WiFi, Server)
- **Inter-VLAN Routing** — ให้แต่ละแผนกสื่อสารกันได้ตามนโยบาย
- **Static Routing** — กำหนดเส้นทางระหว่าง network
- **DHCP** — แจก IP อัตโนมัติตาม VLAN
- **DNS** — ให้บริการ name resolution ภายใน
- **VTP** — จัดการ VLAN ให้สอดคล้องกันทั้ง network
- **ACL** — จำกัดการเข้าถึงตามบทบาทและแผนก

**Tech Stack:** Cisco Packet Tracer, Cisco IOS, VLAN, Routing, ACL

### Hospital DBMS

**Database Management System**

ระบบฐานข้อมูลโรงพยาบาลที่ออกแบบ schema และ query สำหรับจัดการข้อมูลผู้ป่วย แพทย์ และการนัดหมาย

**Highlights:**
- **SQL Server** — relational database
- **VB.NET** — frontend application
- **JOINs** — เชื่อมตารางหลายตาราง (ผู้ป่วย, แพทย์, นัดหมาย)
- **Subqueries** — query ซับซ้อนสำหรับรายงาน

**Tech Stack:** SQL Server, VB.NET, T-SQL
